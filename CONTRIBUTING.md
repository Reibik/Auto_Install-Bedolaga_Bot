# Contributing

1. Не добавляйте реальные токены, домены, IP и `.env`.
2. Сохраняйте Bash-совместимость с версиями из Ubuntu 22.04 и Debian 12.
3. Не используйте широкие destructive-команды для Docker или файловой системы.
4. Любая новая операция удаления должна проверять абсолютный путь и требовать явного подтверждения.
5. Перед Pull Request выполните проверки из раздела «Разработка» в README.
6. После изменения возможностей, команд, требований или интерфейса обновляйте `README.md` и соответствующие разделы `docs/GUIDE.md`: главная страница должна описывать текущее поведение проекта.
7. При изменении меню или версии Manager пересоздавайте его образец: `node scripts/render-menu-preview.mjs`. Правила для изображений и исходный prompt находятся в `docs/assets/README.md`.
