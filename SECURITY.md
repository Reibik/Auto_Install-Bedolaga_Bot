# Security Policy

## Поддерживаемые версии

Исправления безопасности выпускаются для последней версии из ветки `main` и последнего GitHub Release.

## Сообщение об уязвимости

Не публикуйте токены, `.env`, дампы базы, IP клиентов или рабочие домены в Issues. Используйте приватный канал связи владельца репозитория через GitHub Security Advisories.

В сообщении укажите версию Manager, ОС, минимальные шаги воспроизведения и влияние. Все секреты и персональные данные предварительно замените фиктивными.

## Операционные рекомендации

- Запускайте Manager только из официального репозитория.
- Перед выполнением one-line команды можно сначала скачать и прочитать `install.sh`.
- Ограничьте SSH по ключам и обновляйте ОС.
- Храните копии бэкапов вне сервера в зашифрованном виде.
- Не добавляйте `.env` и архивы в Git.
