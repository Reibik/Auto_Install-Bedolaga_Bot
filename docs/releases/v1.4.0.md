# 🎛️ Bedolaga Manager v1.4.0 — компактное меню и удобное управление

### Шесть разделов · Полезный обзор · Узкие терминалы · Точные статусы

Новое меню теперь доступно в **стабильном релизе** — как при новой установке, так и через штатное обновление Manager на уже работающем сервере.

---

## ✨ Что нового

### 🧭 Главное меню стало компактнее

Вместо длинного списка — шесть понятных разделов:

| Раздел | Действия |
|---|---|
| 🐳 **Сервисы** | Статус, запуск, остановка, перезапуск и логи |
| ⬆️ **Обновления** | Версии, все приложения, отдельно Bot / Cabinet, Manager и откат |
| ⚙️ **Настройки** | Bot, стек, Caddy, пути файлов, мастер и применение изменений |
| 💾 **Резервные копии** | Создание, список, восстановление и ежедневные бэкапы |
| 🩺 **Диагностика** | Сведения о сервере, полная проверка, состояния и логи |
| 📊 **Xray Monitoring** | Меню управления Checker и Status Page |

`0` — назад, в главном меню — выход. При выборе сервиса `0` означает «все сервисы», а `b` отменяет выбор. Подменю возвращают назад по Enter без номера, без лишней паузы.

### 📊 Нужная информация сразу на экране

- Общая готовность стека.
- Состояние Bot и Cabinet.
- Включён ли Xray и готовы ли оба его сервиса.
- Дата последнего непустого архива с файлом SHA-256.

> [!NOTE]
> Дата архива — справочная информация. Она не означает, что checksum проверен или восстановление базы протестировано.

### 📐 Оформление для SSH и web-консолей

- Баннеры и подписи адаптируются к ширине **20–80 колонок**.
- Длинные адреса и строки переносятся без разрыва UTF-8 символов.
- При следующем показе меню учитывается изменение размера терминала.
- `NO_COLOR=1` и режим без эмодзи сохранены.
- Опасные действия выделены красным, состояния также подписаны текстом.

Для принудительной ширины:

```bash
BEDOLAGA_UI_WIDTH=40 bedolaga
```

### 🩺 Статусы без ложных тревог

Штатная остановка с кодом `0` больше не называется ошибкой. Ненулевой код завершения, запуск, пауза, перезапуск и недоступный Docker показываются отдельно. Нездоровый стек не выдаётся за остановленный.

## 🚀 Получить новое меню на работающем сервере

От имени `root` выполните:

```bash
bedolaga self-update
bedolaga version
bedolaga
```

Версия этого релиза — **`Bedolaga Manager 1.4.0`**. Команда `self-update` выбирает последний стабильный Release; если позже вышла новая версия, будет установлена она.

> [!TIP]
> Если автообновление включено, Manager также получит новое меню при следующем открытии `bedolaga`, когда истечёт часовой кэш проверки и будет доступен GitHub. `self-update` проверяет обновление сразу. При отключённом автообновлении или в версиях без него требуется ручное обновление.

> [!IMPORTANT]
> Обновление Manager не перезапускает Bot и Cabinet, не переносит базу данных и не требует повторного ввода токенов. Команды CLI и существующие настройки сохраняются. Обновление приложений — отдельное действие `bedolaga update all`.

## 🧙 Установка на чистом сервере

```bash
BEDOLAGA_REF=v1.4.0 BEDOLAGA_EXPECTED_VERSION=1.4.0 bash <(curl -fsSL https://raw.githubusercontent.com/Reibik/Auto_Install-Bedolaga_Bot/v1.4.0/install.sh)
```

Установщик развернёт Bot + Cabinet и предложит добавить Xray Monitoring. Remnawave Panel должна быть установлена заранее.
