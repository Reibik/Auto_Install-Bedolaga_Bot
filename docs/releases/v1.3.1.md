# 🛡️ Bedolaga Manager v1.3.1 — надёжные обновления и бэкапы

### Надёжные обновления · Проверенные бэкапы · Понятная диагностика

Обновление для тех, кто хочет уверенно управлять **Bedolaga Bot + Cabinet + Xray Checker + Status Page**. Мы усилили проверки установщика и устранили случаи, когда ошибка могла остаться незамеченной.

---

## ✨ Главное в этом релизе

### 🔐 Проверяем пакет до установки

- Автообновление Manager получает опубликованный архив конкретного стабильного релиза и проверяет его **SHA-256**.
- Версия внутри архива должна совпадать с выбранным релизом.
- Проверяются **все Bash-скрипты**, а не только первый файл.
- Новая версия проходит пробный запуск во временном каталоге до замены рабочей установки.
- Архивы с небезопасными путями, символическими и жёсткими ссылками отклоняются.

### 🔒 Защищаем рабочую установку

- Блокировки не дают параллельным операциям одновременно заменять Manager.
- После обновления меню открывает установленный файл Manager, а не случайную одноимённую команду из `PATH`.
- Временные каталоги очищаются, в том числе при неудачной установке.
- Ошибка получения исходников больше не подставляет устаревший commit; корректно поддерживаются ветки и теги.

### 💾 Не обновляем без успешного бэкапа

- Ошибки копирования данных, PostgreSQL dump перед обновлением, упаковки и расчёта checksum больше не превращаются в ложное сообщение об успехе.
- Незавершённый архив удаляется вместе с временными файлами.
- При ошибке бэкапа обновление Bot, Cabinet или Xray останавливается до изменения компонентов.

### 🩺 Делаем диагностику точнее

- Остановленные контейнеры отображаются как остановленные, а не отсутствующие.
- Кэш проверки обновлений корректно обрабатывает интервалы с ведущими нулями и дату проверки из будущего.
- Сбой записи кэша проверки не мешает открыть меню.
- Управляющие символы из удалённых заметок об обновлении удаляются перед выводом в терминал.

## 🚀 Как обновить работающий сервер

Запустите от имени `root`:

```bash
bedolaga version
bedolaga self-update
bedolaga version
bedolaga status
```

После установки этого релиза версия будет **`Bedolaga Manager 1.3.1`**. Если позже появился более новый стабильный релиз, `self-update` установит его. Для перехода именно на v1.3.1 из более ранней версии:

```bash
bedolaga self-update v1.3.1
```

> [!TIP]
> При обычном запуске `bedolaga` проверка обновлений выполняется автоматически, с кэшированием на один час. Ручной `self-update` проверяет релиз сразу.

> [!IMPORTANT]
> `self-update` обновляет **только Manager**. Bot, Cabinet и Xray не перезапускаются, повторно вводить токены не нужно. Обновление самих приложений — отдельная команда `bedolaga update all` с предварительными бэкапами.

## 🧙 Новая установка

На чистом поддерживаемом сервере от имени `root`:

```bash
BEDOLAGA_REF=v1.3.1 BEDOLAGA_EXPECTED_VERSION=1.3.1 bash <(curl -fsSL https://raw.githubusercontent.com/Reibik/Auto_Install-Bedolaga_Bot/v1.3.1/install.sh)
```

Мастер установит основной стек и предложит подключить Xray Monitoring. **Remnawave Panel должна быть установлена заранее** — Manager её не разворачивает.

## 📁 Ваши настройки сохраняются

| Данные | Расположение |
|---|---|
| 🤖 Токены и параметры Bot | `/etc/bedolaga/bot.env` |
| 🎛️ Параметры Compose и домены | `/etc/bedolaga/stack.env` |
| 💾 Резервные копии | `/var/lib/bedolaga/backups` |
| 📡 Данные Xray Status Page | `/var/lib/bedolaga/xray-statuspage` |

> [!NOTE]
> PostgreSQL остаётся на версии **15**, существующий том сохраняется. Этот релиз не выполняет миграцию базы на PostgreSQL 18. Откат приложения также не отменяет уже выполненные миграции схемы базы.
